## ആരംഭിക്കാം: മൂന്ന് ഘട്ടത്തിൽ ഫേംവെയർ

**📖 [ചിത്രങ്ങളോടുകൂടിയ സമ്പൂർണ്ണ ഗൈഡ്](https://weigshare.com/posts/WeiG-OpenWrt-AutoBuild-Guide/)**

### 1. സോഴ്‌സ്, ഉപകരണം, പാക്കേജുകൾ തിരഞ്ഞെടുക്കുക

[**【ഓൺലൈൻ കോൺഫിഗറേറ്റർ】**](https://www.weigshare.com/wrt/) തുറന്ന് **【Source】** → **【Branch】** → **【Target System】** → **【Subtarget】** → **【Target Profile】** ക്രമത്തിൽ തിരഞ്ഞെടുക്കുക. ആവശ്യമായ പാക്കേജുകൾ അടയാളപ്പെടുത്തി **【Advanced menuconfig】**, സമയമേഖല, തീം എന്നിവ ആവശ്യാനുസരണം ക്രമീകരിക്കുക. **【ക്രമീകരണം ലോഡ് ചെയ്യുക】** ഉപയോഗിച്ച് ക്രമീകരണ ഫയൽ `*.json`, `.config` അല്ലെങ്കിൽ `config.buildinfo` ഇറക്കുമതി ചെയ്യാം. തുടരുന്നതിനു മുമ്പ് സോഴ്‌സ്, ഉപകരണം, പ്ലഗിനുകൾ എന്നിവ പരിശോധിക്കുക.

### 2. GitHub-ൽ ക്ലൗഡ് ബിൽഡ് അഭ്യർത്ഥിക്കുക

ആദ്യം [**【GitHub-ൽ ലോഗിൻ ചെയ്യുക】**](https://github.com/login). പിന്നെ [**【കോൺഫിഗറേറ്ററിൽ】**](https://www.weigshare.com/wrt/) തിരിച്ചെത്തി **【ക്ലൗഡ് ബിൽഡ് തുടങ്ങുക】** → **【ക്രമീകരണം ഡൗൺലോഡ് ചെയ്ത് GitHub തുറക്കുക】** തിരഞ്ഞെടുക്കുക. ബ്രൗസർ `*.json` ഫയൽ ഡൗൺലോഡ് ചെയ്ത് GitHub Issue ഫോം തുറക്കും. കമ്പ്യൂട്ടറിൽ ഇപ്പോൾ ഡൗൺലോഡ് ചെയ്ത JSON ഫയൽ ബിൽഡ് അഭ്യർത്ഥന ഫീൽഡിലേക്ക് വലിച്ചിട്ട് അപ്‌ലോഡ് ചെയ്യുക; തുടർന്ന് **【Submit new issue】** അമർത്തുക. ബോട്ട് മറുപടിയായി ബിൽഡ് ലിങ്ക് നൽകും.

<details>
<summary><strong>പ്രധാന അറിയിപ്പുകൾ (തുറക്കുക)</strong></summary>

> താഴെ വലതുവശത്തെ ഫ്ലോട്ടിംഗ് ടൂൾബാറിലെ **【പരിശോധന】** ഉപയോഗിച്ച് ക്രമീകരണവും അനുയോജ്യതയും നേരത്തെ പരിശോധിക്കാം. **【ക്രമീകരണം ഡൗൺലോഡ് ചെയ്ത് GitHub തുറക്കുക】** തിരഞ്ഞെടുക്കുമ്പോഴും മുൻപരിശോധന സ്വയമേവ നടക്കും.
>
> പ്രശ്നമുണ്ടെങ്കിൽ നിർദേശിച്ച പരിഹാരം പ്രയോഗിക്കുക അല്ലെങ്കിൽ **【അതേപടി നിലനിർത്തി നിർബന്ധിച്ച് തുടരുക】** തിരഞ്ഞെടുക്കുക. ഇത് അപ്‌സ്ട്രീം സോഴ്‌സിലെ ബഗ് പരിഹരിക്കില്ല; ബിൽഡ് പരാജയപ്പെടാം.
>
> മുൻകൂട്ടി പൂരിപ്പിച്ച വിവരങ്ങൾ നഷ്ടമാകാതിരിക്കാൻ കോൺഫിഗറേറ്റർ സ്വയം തുറന്ന GitHub Issue ഫോം ഉപയോഗിക്കുക.
>
> JSON ഡൗൺലോഡ് ചെയ്താൽ മാത്രം **ബിൽഡ് തുടങ്ങില്ല**; Issue സമർപ്പിക്കണം.
>
> പൊതു Issues, അഭ്യർത്ഥനകൾ, ലോഗുകൾ എന്നിവയിൽ യഥാർത്ഥ പാസ്‌വേഡുകളോ ടോക്കണുകളോ രഹസ്യങ്ങളോ പങ്കിടരുത്.

</details>

### 3. ഫേംവെയർ ഡൗൺലോഡ് ചെയ്യുക

Issue-യിലെ ലിങ്ക് തുറക്കുക അല്ലെങ്കിൽ [**【Actions → Firmware Download】**](https://github.com/weigefenxiang/WeiG-OpenWrt-AutoBuild/actions/workflows/custom-build.yml) സന്ദർശിക്കുക. വിജയിച്ചാൽ **【Artifacts】** ഭാഗത്ത് നിന്ന് ഫേംവെയർ ഡൗൺലോഡ് ചെയ്യുക. `CONFIG` ക്രമീകരണ ഫയലുകളും `BUILD-LOGS` പരിശോധന ലോഗുകളും ആണ്; **ഇവ ഫ്ലാഷ് ചെയ്യാനുള്ള ഫേംവെയർ അല്ല**. ഫയലുകൾ **60 ദിവസം** ലഭ്യമാകും.

## സാധാരണ ചോദ്യങ്ങൾ

<details>
<summary>കൂടുതൽ പാക്കേജുകൾ തിരഞ്ഞെടുക്കുമ്പോൾ RootFS ഇടം തീരുന്നത് എന്തുകൊണ്ട്?</summary>

പാക്കേജുകളും ആശ്രയങ്ങളും RootFS പാർട്ടിഷന്റെ വലുപ്പം കടക്കാം. ഉപകരണം പിന്തുണയ്ക്കുന്നെങ്കിൽ **【Advanced menuconfig】** → **【Target Images】** എന്നതിൽ `TARGET_ROOTFS_PARTSIZE` 512 അല്ലെങ്കിൽ 1024 MiB ആയി ക്രമീകരിക്കുക. ചില ഹാർഡ്‌വെയർ റൂട്ടറുകളിൽ ഫ്ലാഷ് പാർട്ടിഷൻ മാറ്റാനാവില്ല; പാക്കേജുകൾ കുറയ്ക്കുക. കാണുക: [Issue #233](https://github.com/weigefenxiang/WeiG-OpenWrt-AutoBuild/issues/233).

</details>

<details>
<summary>നീണ്ട ബിൽഡ് എന്തുകൊണ്ട് നിർത്തുന്നു?</summary>

GitHub-hosted Runner-ൽ ഒരു Job സാധാരണ ആറു മണിക്കൂറിൽ പരിമിതമാണ്. ഇവിടെ പരിധി **350 മിനിറ്റ്**; ലോഗുകൾക്കായി നിർവഹണം **335 മിനിറ്റിൽ** നിർത്തും. **ഇത് പിന്നീട് തുടരാവുന്ന ഇടവേളയല്ല**.

</details>

<details>
<summary>പരാജയപ്പെട്ട ബിൽഡിന്റെ കാരണം എങ്ങനെ കണ്ടെത്താം?</summary>

**【Artifacts】** ൽ നിന്ന് `BUILD-LOGS` ഡൗൺലോഡ് ചെയ്ത് ആദ്യം `00-SUMMARY.txt` വായിക്കുക. RootFS ഇടം, സമയം, സോഴ്‌സ് കോഡ്, ആശ്രയങ്ങൾ എന്നിവ പരിശോധിക്കുക. [Issue #233](https://github.com/weigefenxiang/WeiG-OpenWrt-AutoBuild/issues/233) കാണുക. മാറ്റങ്ങൾക്ക് ശേഷം **പുതിയ Issue** സൃഷ്ടിക്കുക.

</details>

<details>
<summary>പുതിയ ക്രമീകരണത്തോടെ പഴയ Run വീണ്ടും ഓടിക്കാമോ?</summary>

ഇല്ല. പഴയ Run പഴയ അഭ്യർത്ഥനയും നിശ്ചിത കോഡും ഡാറ്റയും തന്നെ ഉപയോഗിക്കും. പുതിയ ക്രമീകരണം പരിശോധിച്ച് പുതിയ അഭ്യർത്ഥന അയയ്ക്കുക.

</details>
